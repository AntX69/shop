# StorePOS 1.2: ენები და მაღაზიის ვალუტა

ვერსია: 1.2.0-rc.1. Branch: `feature/storepos-v1.2` (V1.1-ის branch-იდან; GitHub-ზე ატვირთულია, `main`-ში merge არ მომხდარა).

## 1. რა დაემატა

- **4 ენა:** ქართული, English, Русский, Español. ქართული რჩება ძირითად ენად.
- **ენის არჩევა სამ ადგილას:**
  - **ინსტალაციისას:** ინსტალერი იწყება ენის არჩევით. არჩეულ ენაზე გაიხსნება პროგრამის პირველი ეკრანები.
  - **შესვლის ეკრანზე:** მარჯვნივ ზემოთ.
  - **ჰედერში, ნებისმიერ დროს:** გლობუსი და `KA` / `EN` / `RU` / `ES`. დაჭერისას სია იხსნება, თითო ენა საკუთარ ენაზეა დაწერილი. ასე სხვა ენაზე მოხვედრილი მომხმარებელი თავის ენას ყოველთვის იპოვის.
- **თითო მომხმარებელს თავისი ენა:** მაგალითად, გამყიდველი რუსულად მუშაობს, მფლობელი ქართულად.
  - შესვლის ეკრანზე სახელის არჩევისას PIN-ის ეკრანი ამ მომხმარებლის ენაზე იხსნება.
  - შესვლის შემდეგ მთელი პროგრამა მის ენაზეა.
- **მაღაზიის ვალუტა:** ლარი (₾), ევრო (€) ან დოლარი ($). ფასები, თვითღირებულება, გაყიდვები, ნისიები, ხარჯები, ანგარიშები, CSV და შეცდომის ტექსტები ერთ, არჩეულ ვალუტაშია.
- **მაღაზიის დროის სარტყელი:** მაგალითად, `Europe/Madrid`. მისით ითვლება:
  - ანგარიშების დღეები („დღეს“, „ეს თვე“);
  - ჩეკის ნომრის თარიღი;
  - დღიური ავტომატური backup.
- **ფორმატი ენის მიხედვით:**

  | ენა | თანხა | წონა |
  |---|---|---|
  | ქართული | `25.50 ₾` (როგორც აქამდე) | `1.250 კგ` |
  | ინგლისური | `$25.50` | `1.250 kg` |
  | რუსული | `25,50 €` | `1,250 кг` |
  | ესპანური | `25,50 €` | `1,250 kg` |

  რუსულსა და ესპანურში წერტილი ათასებს ნიშნავს, ამიტომ იქ ათწილადის მძიმე გამოიყენება. ველებში შეყვანა ორივეთი შეიძლება: `25.50` და `25,50`.

## 2. პირველი გაშვება ახალ მაღაზიაში (მაგ. ესპანეთში)

1. ინსტალერში აირჩიეთ **Español**.
2. პროგრამის პირველ ეკრანზე აირჩიეთ:
   - **ვალუტა** (ევრო);
   - **დროის სარტყელი**: პროგრამა თვითონ სთავაზობს Windows-ის სარტყელს, მაგ. `Europe/Madrid`.
3. შექმენით მფლობელი.

## 3. ვალუტის წესი (მნიშვნელოვანი)

- ვალუტის შეცვლა შესაძლებელია **მხოლოდ მანამ, სანამ მაღაზიას ფულადი ჩანაწერი არ აქვს.** ფულადი ჩანაწერია:
  - გაყიდვა;
  - მარაგის მიღება (საწყისი მარაგის ჩათვლით);
  - ხარჯი;
  - ნისიის დაფარვა ან კორექცია;
  - დაბრუნება.
- მას შემდეგ ვალუტა იკეტება (პარამეტრებში ველი გაუქმებულია და ახსნა ჩანს).
- **თანხები არასდროს გადაიყვანება სხვა ვალუტაში.** მაგალითად, 100 ლარად გაყიდული ნივთი 100 ლარად დარჩება. თუ ჩანაწერებს 34 ევროდ „გადავაქცევდით“, ბუღალტერია გაყალბდებოდა.
- **თქვენი მიმდინარე მაღაზია:** განახლების შემდეგ რჩება ლარში და თბილისის დროით. არაფერი იცვლება.

## 5. როგორ არის აწყობილი (დეველოპერისთვის)

- **გასაღები ქართული ტექსტია:**
  - კოდში წერია `tr('სალარო')`;
  - თარგმანები ინახება ფაილებში `src/shared/i18n/en.ts`, `ru.ts`, `es.ts` (1 314 ტექსტი თითოეულში);
  - `{name}` ნიშნავს ჩასმულ მნიშვნელობას;
  - მრავლობითი ფორმა: `{ one, few, many, other }`.
- **პროგრამის შიდა ნაწილი (main process) კვლავ ქართულად წერს შეტყობინებებს.**
  - ფანჯარა მათ მომხმარებლის ენაზე თარგმნის (`trServer`). ეს მუშაობს მნიშვნელობებით (თანხა, სახელი) და რამდენიმე წინადადებისგან შედგენილ შეტყობინებებზეც.
  - ასე ფინანსური ბირთვის ლოგიკა არ შეცვლილა.
- **ტექსტის შეცვლა ან დამატება:**
  - ახალი ქართული ტექსტის დამატებისას მისი თარგმანი სამივე ფაილში უნდა ჩაიწეროს.
  - `src/shared/i18n/catalog.test.ts` ამოწმებს:
    - კოდის ყოველ ქართულ ტექსტს თარგმანი აქვს;
    - ჩასასმელი ადგილები (`{…}`) ემთხვევა;
    - ეკრანზე `tr()`-ის გარეშე ქართული ტექსტი არ დარჩა.
- **ენის მეხსიერება:**
  - მომხმარებლის ენა: `users.ui_language` (მიგრაცია 12).
  - კომპიუტერის ენა: `ui-language.json` პროფილის საქაღალდეში.
  - ინსტალერის ენა: `install-language.txt` `StorePOS.exe`-ის გვერდით.
  - შესვლის ეკრანი იყენებს ამ ორიდან უფრო ახალს: ინსტალერის ენას ან პროგრამაში ბოლოს არჩეულს.
- **ვალუტა და დროის სარტყელი:** `app_settings.currency` / `timezone`. ორივე არსებობდა პირველი ვერსიიდან (GEL / Asia/Tbilisi), ახლა გამოიყენება.

## 6. ცნობილი შეზღუდვები

- **თარგმანები ავტომატურად შექმნილია (Claude) და მშობლიური ენის მცოდნის შემოწმებას საჭიროებს**, განსაკუთრებით მაღაზიის ტერმინები:
  - „ნისია“: credit / в долг / a crédito;
  - „ჩამოწერა“: write-off / списание / condonación, baja;
  - „გაცვლა“: exchange / обмен / cambio;
  - „ჩეკი“: receipt / чек / ticket.

  შესწორება `en.ts` / `ru.ts` / `es.ts` ფაილებში ხდება.
- **ქართული ინსტალერი:**
  - ძირითადი გვერდები NSIS-ის ქართული ფაილიდანაა;
  - „ვისთვის დავაინსტალიროთ“ გვერდის ტექსტები ჩვენ დავამატეთ;
  - electron-builder-ის რამდენიმე საკუთარ შეტყობინებას (მაგ. „პროგრამა გაშვებულია, დახურეთ“) ქართული ვერსია არ აქვს და ინგლისურად ჩანს.

  ინგლისურ, რუსულ და ესპანურ ინსტალერს ეს პრობლემა არ აქვს.
- **ჩუმი ინსტალაცია (`/S`):** ინსტალერი ენას არ კითხულობს და Windows-ის ენას იღებს, თუ ის ოთხიდან ერთ-ერთია. სხვა შემთხვევაში ქართულს.
- **V1.1 (RC2) პროგრამა V1.2-ის ბაზაზე:** ირთვება და მუშაობს, მაგრამ ენას და ვალუტას არ იცნობს და ყველგან ₾-ს აჩვენებს. ლარის მაღაზიისთვის ეს უვნებელია. ევროს მაღაზიაში RC2 არ უნდა დაყენდეს.
- **V1.2 ბაზას, რომელიც მომავალი, უფრო ახალი ვერსიით შეიქმნა, აღარ ხსნის.**
- **CSV-ში თარიღი UTC-შია,** როგორც აქამდე.
