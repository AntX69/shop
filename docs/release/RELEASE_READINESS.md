   - ამ ეტაპზე ნაპოვნი 14 რეალური ხარვეზი გასწორდა (§3): კამერა, OCR, სკანერი, Backup, უსაფრთხოება, სტაბილურობა.

2. **რა შემოწმდა:** ყველა ავტომატური ნაკრები **საბოლოო ინსტალერის** ბინარზე (§4): 129 unit, 28 acceptance, 40 კამერა/OCR/სკანერი, 11 გადატვირთვა/გათიშვა, 18 DR, 16 დატვირთვა, 15 M12-ის განახლება, 14 ინსტალერის განახლება, 13 ძველი აუდიტის სცენარი, 2-საათიანი soak. ასევე უსაფრთხოების და კონფიდენციალურობის მიმოხილვა ([SECURITY_PRIVACY_REVIEW.md](SECURITY_PRIVACY_REVIEW.md)).
3. **მხოლოდ ფიზიკურ მოწყობილობაზე დამოკიდებული:**

   - კონკრეტული USB სკანერის მოდელი;

   ამათ პროგრამული მხარე მზადაა (DP-150-ზე მხოლოდ მზადება).
4. **მზადაა თუ არა:** **დიახ, პროგრამული ნაწილის რელიზისთვის.** ყველა სავალდებულო პროგრამული კრიტერიუმი შესრულებულია და შემოწმებულია რეალურ ინსტალირებულ პროგრამაზე. ცნობილი P0/P1 ხარვეზი არ არის. „Production Ready“ სრული სისტემისთვის (სკანერითა და OCR-ით) ცხადდება მხოლოდ მოწყობილობების შემოწმების შემდეგ (§2, HARDWARE PENDING).
5. **საბოლოო ინსტალერი:** `StorePOS-Setup-1.0.0-rc.2.exe`, SHA-256 `e5fa50f5a9714dfd6f17d6e6e3cc6d47d14f41539645fd66dd26e5081dd3424c`. თუ OCR-ის ან სკანერის შემოწმება კოდის ცვლილებას მოითხოვს, იქნება ახალი build ახალი ნომრითა და ჰეშით.
