# StorePOS 1.1.0-rc.1: მზადყოფნის ანგარიში

თარიღი: 2026-11-20, განახლებულია 2026-11-21 დამოუკიდებელი გადამოწმებით (§11). Branch: `feature/storepos-v1.1` (ლოკალური, GitHub-ზე **არ არის** ატვირთული). საწყისი: RC3 `3f4f65d`. ეტაპების დეტალები: [../V1.1_PROGRESS.md](../V1.1_PROGRESS.md).

## 1. დასკვნა

**1.1.0-rc.1 მზადაა იზოლირებული ხელით შემოწმებისთვის, საბოლოო ვერსიად ჯერ არა.**

- **იზოლირებულად შესამოწმებლად გამოიყენეთ `StorePOS-Test-Setup-1.1.0-rc.1.exe`** (§9). პროგრამის ფაილები იგივეა, რაც RC1-ში. განსხვავდება მხოლოდ სახელი exe-სა და `package.json`-ში (§11.3). ის ცალკე დგება და მონაცემებს ცალკე საქაღალდეში ინახავს (`%APPDATA%\StorePOS-Test`). RC3-ს და მაღაზიის ბაზას არ ეხება.
- **`StorePOS-Setup-1.1.0-rc.1.exe` ამ კომპიუტერზე იზოლირებული არ არის.** RC3 აქ „ყველა მომხმარებლისთვისაა“ დაყენებული (`C:\Program Files\StorePOS`). ინსტალერი ამას ცნობს და ნაგულისხმევად RC3-ს ადგილზე ანაცვლებს. პირველივე გაშვებისას მაღაზიის ბაზა V1.1-ზე გადადის. ასეა Windows-ის სხვა მომხმარებლიდან გაშვებისასაც (§11.4). ეს ნამდვილი განახლებაა და მხოლოდ შემოწმების შემდეგ უნდა გაკეთდეს.
- 30-წუთიანი soak-ის ჩავარდნის მიზეზი **ტესტის დეფექტი** აღმოჩნდა: ამას ადასტურებს მტკიცებულება და რეპროდუქცია. დამგეგმავი ყველა შემოწმებულ სიტუაციაში სწორად მუშაობს (§11.1–11.2). ტესტი გასწორდა და ხელახლა გაეშვა (§11.1).
- **ნაპოვნია ერთი რისკი, RC1-ში დაცვა არ არის:** თუ ძველი RC3 პროგრამა V1.1-ზე გადაყვანილ ბაზას გახსნის, ის მუშაობს და თვითღირებულების აღრიცხვას ჩუმად აზიანებს (§11.4). ეს ხდება მხოლოდ მაშინ, თუ RC3 ინსტალაციის შემდეგ კვლავ დარჩა, ან ხელახლა დადგა. ამის თავიდან ასაცილებლად იხ. §10. დაცვა კოდში შესაძლებელია RC2-ში.
- დანარჩენი ყველა შემოწმება გავიდა. ფიზიკური მოწყობილობები შეუმოწმებელია (§7).

DevTools დაყენებულ ვერსიაში გამორთულია.

- სერვისებში მეორე შემოწმება: გადახდის მეთოდი, ფასდაკლება, კონკრეტული ჩეკი, ფასი/თვითღირებულება (მხოლოდ რეალური ცვლილებისას), გაცვლა ნისიით.
- თვითღირებულება/მოგება/COGS/მარაგის ღირებულება ჩანს მხოლოდ „მოგება და თვითღირებულება“ (`reports.profit`) უფლებით (ფილტრიც და სერვისიც). ნაშთის რიცხვები ჩანს მხოლოდ „ნაშთის რაოდენობებით“. CSV ექსპორტში თვითღირებულება/მოგება არ არის.
