# StorePOS V1.0 — ხელით შესამოწმებელი ჩამონათვალი

ავტომატური ტესტებით (96 + 28 + 15 + 16) შემოწმებულია ბიზნესლოგიკა, ინსტალერი და პროგრამა API-ს დონეზე. ეს ჩამონათვალი ამოწმებს იმას, რაც მხოლოდ ადამიანს და რეალურ მოწყობილობას შეუძლია: **ფიზიკურ სკანერს, კამერას, ახალ ფორმებს „დაკლიკვით“, შენს ეკრანს და მასშტაბს**.

**სად:** სასურველია ჯერ სატესტო კომპიუტერზე ან Windows-ის ცალკე მომხმარებელზე. თუ პირდაპირ მაღაზიის კომპიუტერზეა, ტესტის ბოლოს გამოიყენე **ბაზის განულება** (§13) ან დააინსტალირე თავიდან, რომ რეალური მუშაობა სუფთა ბაზით დაიწყოს.

**როგორ ჩაწერო:** ყოველ პუნქტზე ✅ / ❌ და შენიშვნა. ❌-ზე გადაიღე ეკრანის სურათი (Win + Shift + S) და მომწერე ნომერი, მაგ. „7.4 ❌“.

**სავარაუდო დრო:** 60–90 წუთი (სკანერი და კამერა — ყველაზე მეტი).
