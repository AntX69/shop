# Financial Reconciliation Report — StorePOS V1.0

ყველა თანხა ინახება და ითვლება **მთელ თეთრებში** (INTEGER). Float არ გამოიყენება; პროპორციული განაწილება და ნაწილობრივი დაბრუნება ითვლება BigInt-ით (`src/shared/money.ts`).

## 2. ფინანსების გვერდის ციფრები

```
მთლიანი გაყიდვები        = პერიოდის გაყიდვების გადახდილი თანხა (ფასდაკლების შემდეგ)
დაბრუნებები              = პერიოდში დაბრუნებული საქონლის ღირებულება (გადახდილი ფასით)
წმინდა გაყიდვები          = მთლიანი − დაბრუნებები
გაყიდულის თვითღირებულება = პერიოდში გაყიდული ცალების FIFO ფასი
უკუგატარებული COGS       = პერიოდში დაბრუნებული ცალების თავდაპირველი FIFO ფასი
მთლიანი მოგება           = წმინდა გაყიდვები − (გაყიდული − უკუგატარებული)
საოპერაციო შედეგი         = მთლიანი მოგება − დაზიანებული საქონელი − ჩამოწერილი ნისია − ხარჯები
ნაღდი ნაკადი              = ნაღდი გაყიდვებიდან + დაფარვებიდან − კლიენტებისთვის დაბრუნებული ნაღდი
```

თუ რომელიმე ცალის თვითღირებულება უცნობია: „მთლიანი მოგება“ და „საოპერაციო შედეგი“ = **უცნობია** (null), ცალკე ჩანს „არასრული“ ციფრი მხოლოდ ცნობილი ფასებით და უცნობი ცალების რაოდენობა.
