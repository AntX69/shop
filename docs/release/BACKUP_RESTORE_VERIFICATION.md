# Backup / Restore Verification Report — StorePOS V1.0

## 1. რა ინახება და სად

- მონაცემები: `%APPDATA%\StorePOS\data\` — `store.db` (SQLite, WAL, `synchronous=FULL`), `images\` (ფოტოები ფაილებად), `backups\`.
- Backup ფაილი: `storepos_<ტიპი>_<თბილისის დრო>.posbackup` — ერთი JSON ფაილი: მეტამონაცემები (თავში), ბაზის snapshot (base64), ფოტოები, პარამეტრები, SHA-256.
- ტიპები: `auto` (ყოველდღიური), `manual` (ხელით), `prereset` (განულებამდე), `prerestore` (აღდგენამდე).

## 2. როგორ მუშაობს

| ოპერაცია | დეტალები |
|---|---|
| Snapshot | `PRAGMA integrity_check` → `VACUUM INTO` (თანმიმდევრული ასლი პროგრამის მუშაობისას) → SHA-256 → ჩაწერა დროებით ფაილში და rename (ელექტროენერგიის გათიშვისას ნახევრად ჩაწერილი ფაილი არ რჩება) |
| ყოველდღიური | main process-ის scheduler: გაშვებიდან 1 წუთში, შემდეგ ყოველ 30 წუთში; დღეში ერთი ასლი (თბილისის თარიღით), ვინც არ უნდა იყოს შესული |
| Retention | ინახება უახლესი N ავტომატური ასლი (ნაგულისხმევი 30, 3–365); ხელით და უსაფრთხოების ასლები არასდროს იშლება |
| USB / მეორე საქაღალდე | ყოველი ასლი იქაც იწერება; თუ დისკი არ არის, მთავარი ასლი მაინც იქმნება და შეცდომა იწერება ჟურნალში |
| Restore | ① სრული შემოწმება (ფორმატი, SHA-256, SQLite header, integrity_check, აუცილებელი ცხრილები, სქემა არ არის უფრო ახალი) → ② მიმდინარე მდგომარეობის `prerestore` ასლი (თუ ვერ შეიქმნა, აღდგენა ჩერდება) → ③ ბაზის დახურვა → ④ მიმდინარე ფაილები გვერდზე → ⑤ ახალი ფაილი ადგილზე → ⑥ ფოტოები მხოლოდ `images`-ში → ⑦ გახსნა, მიგრაცია, შემოწმება → ⑧ ნებისმიერ შეცდომაზე ძველი ფაილები ბრუნდება ზუსტად |
| განულება | Owner PIN (lockout-ით) → `prereset` ასლი და მისი შემოწმება → ერთ ტრანზაქციაში ყველაფრის წაშლა (FK შემოწმება commit-ზე) |
| განახლება | ახალი ვერსია ძველ ბაზას ავტომატურად აახლებს; მანამდე იქმნება `store.db.before_migration_vN_*.bak` |

## 4. რეკომენდებული რუტინა მაღაზიაში

1. პარამეტრებში აირჩიე **დამატებითი საქაღალდე USB დისკზე** — ყოველი ასლი იქაც ჩაიწერება.
2. კვირაში ერთხელ USB შეაერთე და შეამოწმე, რომ იქ ახალი ფაილებია; შეინახე სხვა ადგილას.
3. თვეში ერთხელ სიიდან „შემოწმება“ ერთ ასლზე.
4. კომპიუტერის შეცვლისას: ახალ კომპიუტერზე დააყენე StorePOS → შექმენი დროებითი Owner → პარამეტრები → „ფაილიდან აღდგენა…“ → შედი ძველი Owner-ის PIN-ით (დეტალურად: `docs/UPDATE_GUIDE.md` §5).
