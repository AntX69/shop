# StorePOS — Windows Desktop Installation & Offline Operations Guide

სრულიად ლოკალური, ოფლაინ Windows Desktop პროგრამა მაღაზიის მართვის, სალაროს, პროდუქციის, მარაგებისა და ნისიებისთვის.

---

## 1. სისტემური მოთხოვნები (System Requirements)

- **ოპერაციული სისტემა:** Windows 10 (64-bit) ან Windows 11 (64-bit).
- **პროცესორი:** Intel Core i3 / AMD Ryzen 3 ან უკეთესი.
- **ოპერატიული მეხსიერება (RAM):** მინიმუმ 4 GB (რეკომენდებულია 8 GB).
- **დისკის თავისუფალი ადგილი:** მინიმუმ 500 MB (მონაცემთა ბაზისა და სურათების ზრდის გათვალისწინებით).
- **ინტერნეტი:** **არ არის საჭირო**. პროგრამა შექმნილია 100% ოფლაინ რეჟიმისთვის (Air-gapped PC).
- **პერიფერიული მოწყობილობები:**
  - ნებისმიერი სტანდარტული USB შტრიხკოდის სკანერი (მუშაობს კლავიატურის ემულაციით / HID რეჟიმში).
  - (არასავალდებულო) USB ვებკამერა ან ლეპტოპის ჩაშენებული კამერა ხელნაწერი 5-ნიშნა კოდების ოფლაინ ამოცნობისთვის (OCR).

---

## 2. ინსტალაცია Windows-ზე (Installation Steps)

1. გადმოწერეთ ან USB ფლეშკიდან გადმოიტანეთ საინსტალაციო ფაილი:
   ```
   StorePOS-Setup-1.0.0.exe
   ```
2. გაუშვით ფაილი ადმინისტრატორის ან ჩვეულებრივი მომხმარებლის უფლებით.
3. NSIS ინსტალატორი შემოგთავაზებთ ინსტალაციის საქაღალდის არჩევას (ნაგულისხმევი: `C:\Program Files\StorePOS` ან `%LOCALAPPDATA%\Programs\StorePOS`).
4. ინსტალაციის დასრულების შემდეგ ავტომატურად შეიქმნება:
   - მალსახმობი სამუშაო მაგიდაზე (**StorePOS Desktop**).
   - ჩანაწერი Start მენიუში.

---

## 3. მონაცემთა ადგილმდებარეობა და უსაფრთხოება (Data Directory)

ყველა მონაცემი ინახება ლოკალურად თქვენს კომპიუტერზე:
- **მონაცემთა ბაზა:** `%APPDATA%\StorePOS\data\store.db`
- **SQLite WAL ლოგები:** `store.db-wal` და `store.db-shm`
- **სურათები:** ლოკალურ ბაზაში შენახული ოპტიმიზებული Base64/ფაილური რეპოზიტორია.

> **უსაფრთხოების გარანტია:** არცერთი ბაიტი არ იგზავნება გარე სერვერზე ან ქლაუდში. მონაცემთა ბაზა იყენებს SQLite WAL (Write-Ahead Logging) რეჟიმს, რაც იცავს მონაცემებს დაუგეგმავი ელექტროენერგიის გათიშვისას (Crash Resilient).

---

## 4. პირველადი გაშვება და მომხმარებლების კონფიგურაცია

1. **მფლობელის (Owner) შექმნა:**
   - პროგრამის პირველი გაშვებისას სისტემა მოგთხოვთ მაღაზიის მფლობელის სახელის და **4–6 ნიშნა PIN კოდის** მითითებას.
   - სატესტო რეჟიმში ნაგულისხმევი მფლობელის PIN არის: `1234`.
2. **გამყიდველების (Sellers) დამატება:**
   - შედით მენიუში **თანამშრომლები (F7)**.
   - დააჭირეთ „+ ახალი თანამშრომელი“ და მიუთითეთ სახელი და ინდივიდუალური PIN კოდი.
   - გამყიდველის როლს შეზღუდული აქვს თვითღირებულების, მოგებისა და სისტემური პარამეტრების ნახვა.
3. **სესიის დაბლოკვა (Quick Lock):**
   - დააჭირეთ კლავიატურაზე **F12** ან ზედა მარჯვენა ღილაკს „ჩაკეტვა“.
   - 15 წუთის უმოქმედობის შემდეგ სისტემა ავტომატურად იბლოკება.

---

## 5. სარეზერვო ასლები (Backup & Restore USB-ზე)

რეკომენდებულია კვირაში ერთხელ მაინც ერთიანი სარეზერვო ასლის შენახვა გარე USB ფლეშკაზე:
1. შედით მენიუში **პარამეტრები / Backup (F8)** (მხოლოდ მფლობელისთვის).
2. დააჭირეთ **„ერთიანი ასლის ჩამოტვირთვა (.posbackup)“**.
3. ფაილი შეიცავს:
   - SQLite მონაცემთა ბაზის სრულ სნეპშოტს.
   - პროდუქციის ყველა ფოტოსურათს.
   - მაღაზიის კონფიგურაციას.
   - **SHA-256 კრიპტოგრაფიულ ჰეშს** მთლიანობის დასაცავად.
4. **აღდგენისას:**
   - სისტემა ახორციელებს `PRAGMA integrity_check`-ს.
   - დაუყოვნებლივ ქმნის არსებული ბაზის სარეზერვო ასლს (`store.db.before_restore_<timestamp>`).
