# StorePOS — ინსტალაციის გზამკვლევი (Windows 10/11)

## 1. მოთხოვნები

- Windows 10 ან 11, **64-bit**. (შემოწმებულია Windows 11 Pro-ზე; Windows 10-ზე ჯერ არ შემოწმებულა.)
- 4 GB RAM (რეკომენდებულია 8 GB), დისკზე ~600 MB + მონაცემები და ასლები.
- ინტერნეტი **არ არის საჭირო** — არც ინსტალაციისას, არც მუშაობისას. Node.js ან npm არ სჭირდება.
- სურვილისამებრ: USB შტრიხკოდის სკანერი (კლავიატურის რეჟიმი), ვებკამერა (ხელნაწერი 5-ნიშნა კოდისთვის), USB დისკი ასლებისთვის.

## 2. ინსტალაცია

1. დააკოპირე `StorePOS-Setup-1.0.0.exe` კომპიუტერზე (მაგ. USB-დან).
   - შემოწმება (სურვილისამებრ): PowerShell → `Get-FileHash StorePOS-Setup-1.0.0.exe` → უნდა იყოს
     `EB7C761D17D6630356B94EAB3A1E6016118A232D22FFB67A4DD0309ACE6D9D08`.
2. ორჯერ დააწკაპუნე. ინსტალერი ციფრული ხელმოწერის გარეშეა, ამიტომ Windows შეიძლება აჩვენოს **„Windows protected your PC“** → **More info** → **Run anyway**.
3. აირჩიე საქაღალდე (ნაგულისხმევი: `%LOCALAPPDATA%\Programs\StorePOS`, ადმინისტრატორის უფლება არ სჭირდება) → Install.
4. იქმნება Desktop-ისა და Start Menu-ის მალსახმობი **StorePOS**.

## 3. პირველი გაშვება

1. გახსენი StorePOS. ბაზა ცარიელია: სატესტო პროდუქტი, კლიენტი ან PIN არ არის.
2. შეიყვანე **მფლობელის სახელი და PIN** (4–6 ციფრი, ორჯერ). წინასწარ განსაზღვრული PIN არ არსებობს — დაიმახსოვრე შენი.
3. **პერსონალი (F7)** → თანამშრომლის დამატება როლით „გამყიდველი“ და საკუთარი PIN-ით.
4. **პარამეტრები (F8)**:
   - მაღაზიის სახელი, ავტომატური ჩაკეტვის დრო;
   - სარეზერვო საქაღალდე (სურვილისამებრ) და **დამატებითი საქაღალდე USB დისკზე** (რეკომენდებულია);
   - „სარეზერვო ასლის შექმნა ახლავე“ — შეამოწმე, რომ ფაილი გაჩნდა.

## 4. სად ინახება მონაცემები

| რა | სად |
|---|---|
| ბაზა | `%APPDATA%\StorePOS\data\store.db` (+ `store.db-wal`, `store.db-shm`) |
| პროდუქტის ფოტოები | `%APPDATA%\StorePOS\data\images\` |
| ავტომატური/ხელით ასლები | `%APPDATA%\StorePOS\data\backups\` (ან არჩეული საქაღალდე) |
| პროგრამა | ინსტალაციის საქაღალდე (მონაცემებს არ შეიცავს) |

მონაცემები ამ კომპიუტერს არ ტოვებს: პროგრამა ბლოკავს ყველა ინტერნეტ-მოთხოვნას. პროგრამის წაშლა ან განახლება `%APPDATA%\StorePOS`-ს **არ შლის**.

## 5. მოწყობილობები

- **შტრიხკოდის სკანერი:** USB HID (კლავიატურის) რეჟიმი, სკანირების ბოლოს **Enter** (სკანერის სახელმძღვანელოს „suffix CR“ კოდით). სალაროში კურსორი ძებნის ველშია; სკანირების შემდეგ იხსნება პროდუქტის ფანჯარა და კალათაში დამატება საჭიროებს დადასტურებას.
- **ვებკამერა:** სალარო → კამერის ღილაკი. პირველ ჯერზე Windows-ში უნდა იყოს ჩართული *Settings → Privacy → Camera → Let desktop apps access your camera*.
- **DATECS DP-150:** ამ ვერსიაში არ არის დაკავშირებული (იხ. `docs/HARDWARE_STATUS.md`).

## 6. პრობლემები

| სიმპტომი | რა ვქნა |
|---|---|
| „მონაცემთა ბაზა ვერ გაიხსნა“ ფანჯარა | გადატვირთე კომპიუტერი. თუ მეორდება — **არაფერი წაშალო**; ასლები არის `data\backups`-ში; დაუკავშირდი მხარდაჭერას. |
| „ბევრი არასწორი PIN მცდელობა“ | დაელოდე მითითებულ დროს, ან Owner-მა პერსონალში დააჭიროს „განბლოკვა“. |
| Owner-ის PIN დაგავიწყდა | PIN-ის ნახვა ან „აღდგენა“ პროგრამაში შეუძლებელია (დაცვის მიზნით). ამიტომ **შექმენი მეორე Owner** (მაგ. ოჯახის წევრისთვის): მას შეუძლია პერსონალში შენი PIN-ის განულება. ერთადერთი Owner-ის PIN-ის დაკარგვისას საჭიროა ტექნიკოსი. |
| კამერა არ ჩანს | შეამოწმე Windows-ის კამერის კონფიდენციალურობის პარამეტრი და რომ სხვა პროგრამა კამერას არ იყენებს. |
| სკანერი ციფრებს წერს, მაგრამ არ ეძებს | სკანერზე ჩართე Enter (CR) სუფიქსი. |

## 7. წაშლა

*Settings → Apps → StorePOS → Uninstall*. პროგრამა და მალსახმობები წაიშლება; მონაცემები `%APPDATA%\StorePOS`-ში რჩება. სრულად წასაშლელად (მაგ. კომპიუტერის გაყიდვამდე) ჯერ გააკეთე ასლი, შემდეგ ეს საქაღალდე ხელით წაშალე.
