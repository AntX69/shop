# StorePOS: ინსტალაცია, განახლება და სარეზერვო ასლები

ვერსია: **1.0.0-rc.2**. ინსტალერი: `StorePOS-Setup-1.0.0-rc.2.exe`.

## 1. მოთხოვნები

- Windows 10 ან 11, **64-bit**. შემოწმებულია Windows 11 Pro-ზე. Windows 10-ზე ჯერ არ შემოწმებულა.
- 4 GB RAM (რეკომენდებულია 8 GB). დისკზე ~600 MB პროგრამისთვის, პლუს მონაცემები და ასლები. ერთი ასლი ≈ ბაზა + ყველა ფოტო; 30 ავტომატური ასლი ინახება.
- ინტერნეტი **არ სჭირდება**: არც ინსტალაციას, არც მუშაობას.
- სურვილისამებრ: USB შტრიხკოდის სკანერი ([hardware/SCANNER_SETUP_KA.md](hardware/SCANNER_SETUP_KA.md)), ვებკამერა ([hardware/OCR_FIELD_TEST_KA.md](hardware/OCR_FIELD_TEST_KA.md)), USB დისკი ასლებისთვის.

## 2. ფაილის შემოწმება (რეკომენდებულია)

ინსტალერი ხელმოუწერელია, ამიტომ მისი ნამდვილობა SHA-256-ით მოწმდება:

```powershell
Get-FileHash .\StorePOS-Setup-1.0.0-rc.2.exe -Algorithm SHA256
```

უნდა დაემთხვეს: `E5FA50F5A9714DFD6F17D6E6E3CC6D47D14F41539645FD66DD26E5081DD3424C`

თუ არ ემთხვევა, ფაილი არ გაუშვა (დაზიანებულია ან სხვა ფაილია).

## 3. ახალი ინსტალაცია

1. ორჯერ დააწკაპუნე `StorePOS-Setup-1.0.0-rc.2.exe`-ზე.
2. Windows SmartScreen აჩვენებს **„Windows protected your PC“**. ეს ხელმოუწერელი პროგრამის სტანდარტული გაფრთხილებაა: **More info** → **Run anyway**.
3. აირჩიე საქაღალდე (ნაგულისხმევი: `%LOCALAPPDATA%\Programs\StorePOS`, ადმინისტრატორის უფლება არ სჭირდება) → **Install**.
4. Desktop-ზე და Start Menu-ში ჩნდება **StorePOS**.
5. პირველი გაშვება: ბაზა ცარიელია, სატესტო პროდუქტი და PIN არ არის. შექმენი **Owner** (სახელი + 4–6 ციფრიანი PIN, ორჯერ). რეკომენდებულია 6 ციფრი.
6. პერსონალი (F7): დაამატე გამყიდველები, თითოეულს საკუთარი PIN. სასურველია **მეორე Owner** (მაგ. ოჯახის წევრი): დავიწყებული PIN-ის განულება მხოლოდ სხვა Owner-ს შეუძლია.
7. შესვლის ეკრანზე უნდა ეწეროს **„ვერსია 1.0.0-rc.2“**.

## 4. განახლება ძველი ვერსიის თავზე (მაგ. RC1 → RC2)

1. **ჯერ ასლი:** პარამეტრები (F8) → „სარეზერვო ასლის შექმნა ახლავე“ (USB მიერთებული).
2. **დახურე StorePOS.** თუ ღია დარჩა, ინსტალერი ჯერ შეგეკითხება და მერე დახურავს. ჩაწერილი გაყიდვები არ იკარგება, დაუსრულებელი კალათა კი დაიკარგება.
3. გაუშვი ახალი ინსტალერი იმავე საქაღალდეზე. ძველი ვერსია ავტომატურად შეიცვლება. Windows-ის პროგრამების სიაში ერთი StorePOS დარჩება, ახალი ვერსიით.
4. გახსენი StorePOS და შედი ძველი PIN-ით. შეამოწმე, რომ პროდუქტები, ნაშთები, ნისიები და ფინანსები ადგილზეა. შესვლის ეკრანზე ახალი ვერსია უნდა ეწეროს.

მონაცემები (`%APPDATA%\StorePOS`) განახლებისას **არ იშლება**. ეს შემოწმებულია ცალკე სატესტო ინსტალაციაზე („1.0.0“ → „1.0.0-rc.2“, ძველი პროგრამა გაშვებული იყო). ნახე [release/TEST_REPORT.md](release/TEST_REPORT.md).

## 5. სარეზერვო ასლები: ერთხელ დასაყენებელი

პარამეტრები (F8):

1. **სარეზერვო საქაღალდე:** დატოვე ნაგულისხმევი (`%APPDATA%\StorePOS\data\backups`) ან აირჩიე სხვა დისკი.
2. **დამატებითი ასლი (USB):** „არჩევა“ → USB დისკზე საქაღალდე, მაგ. `E:\StorePOS-Backups`. ყოველი ასლი ორივე ადგილას ჩაიწერება. USB ფონურ რეჟიმში იწერება და სალაროს არ აფერხებს.
3. **ავტომატური ასლი:** ჩართული (ნაგულისხმევად). დღეში ერთხელ, პროგრამის ჩართვიდან მალევე, როცა სალარო ~20 წამი არ გამოიყენება (მაქსიმუმ 30 წუთის ლოდინი). ინახება ბოლო 30.
4. „სარეზერვო ასლის შექმნა ახლავე“ → შეტყობინებაში უნდა ეწეროს ორივე გზა (კომპიუტერი და USB).

**ყოველდღიური წესი:**
- დღის ბოლოს „სარეზერვო ასლის შექმნა ახლავე“ (ავტომატური ასლი დღის დასაწყისშია).
- კვირაში ერთხელ USB შეინახე მაღაზიის გარეთ, ან გამოიყენე ორი USB მონაცვლეობით.
- თვეში ერთხელ ბოლო ასლზე „შემოწმება“ → „მთლიანობა დადასტურებულია“.

ხელით ასლის შექმნისას პროგრამა ~2 წამით „ფიქრობს“ (30 MB ფოტოზე). ეს ნორმალურია.

**კონფიდენციალურობა:** ასლში არის მომხმარებლები, ტელეფონები, ნისიები და PIN-ების ჰეშები. არ ატვირთო GitHub-ზე ან საჯარო ადგილას. თუ ასლების საქაღალდეს OneDrive-ში (Desktop/Documents) აირჩევ, ასლები ღრუბელშიც აიტვირთება. ეს შენი გადაწყვეტილებაა.

## 6. აღდგენა

ნაბიჯ-ნაბიჯ ყველა შემთხვევისთვის (ახალი კომპიუტერი, შეცდომით წაშლა, დაზიანებული ბაზა, სავსე დისკი, USB-ის გარეშე): [DISASTER_RECOVERY_KA.md](DISASTER_RECOVERY_KA.md).

## 9. წაშლა

Settings → Apps → StorePOS → Uninstall. პროგრამა და მალსახმობები იშლება, მონაცემები `%APPDATA%\StorePOS`-ში რჩება. სრულად წასაშლელად (მაგ. კომპიუტერის გაყიდვამდე) ჯერ გააკეთე ასლი, შემდეგ ეს საქაღალდე ხელით წაშალე.
